# API Architect Audit

**Scanner orientado a API Architect / Tech Lead** para REST/OpenAPI/Express.

Foca em:
- **Design de Endpoints** (HTTP methods, naming, nesting)
- **Contratos** (schemas, tipos, enums)
- **Versionamento** (URL path, header, deprecation)
- **Status HTTP & Erros** (consistência, documentação)
- **Paginação & Filtros** (limites, query params)
- **Autenticação** (Bearer, API Key, permissões)

Use: `/api-architect-audit`

Idioma: **português**
