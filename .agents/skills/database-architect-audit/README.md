# Database Architect Audit

**Scanner orientado a DBA / Database Architect** para Prisma/PostgreSQL/MySQL.

Foca em:
- **Schema Design** (tipos, relacionamentos, constraints)
- **Índices Estratégicos** (FK, filtros, joins)
- **Migrations Seguras** (reversíveis, sem downtime)
- **Integridade de Dados** (NOT NULL, unique, foreign keys)
- **Query Optimization** (eager loading, N+1 queries)

Use: `/database-architect-audit`

Idioma: **português**
