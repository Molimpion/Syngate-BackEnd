# Formato de Saída (Performance Audit)

Gere uma tabela de resumo de desempenho:
| 🔴 Gargalos Críticos | 🟠 Alto Impacto | 🟡 Oportunidades |
|----------------------|-----------------|------------------|

Em seguida, liste cada problema encontrado com:
1. **Local:** Arquivo e linha.
2. **Gargalo:** O que está deixando o código lento ou consumindo memória.
3. **Otimização Sugerida:** Patch de código refatorado.
