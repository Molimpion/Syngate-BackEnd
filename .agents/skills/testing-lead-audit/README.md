# Testing Lead Audit

**Scanner orientado a QA Lead / Testing Architect** para Node.js/TypeScript/Jest/Vitest.

Foca em:
- **Cobertura real** (comportamento, não só linhas)
- **Qualidade de testes** (frágeis, mocks excessivos, snapshots)
- **Pirâmide de testes** (unitários, integração, E2E/contrato)
- **Testes de BD** (seed, teardown, migrations)
- **Testes de API** (status HTTP, schemas, auth/authz)
